    What is inside

    A world model with real consequences

    Long-Horizon Planning

    Projects unfold over dependencies, cure times, permit delays, material ETAs, inspections, and deadline pressure.

    Multi-Agent Coordination

    Structural, MEP, finishing, admin, and subcontractor agents each carry different costs, constraints, and behaviors.

    Professional Safety Rules

    OSHA-style checks penalize unsafe crane work, fall protection failures, excavation hazards, welding risks, and missing reports.

    Trainable Feedback

    Dense progress rewards, budget efficiency, schedule bonuses, safety penalties, invalid-action penalties, and anti-hack checks.

    Reward design

    Multiple checks make shortcuts expensive

    ProgressDependency-valid task completion.
    BudgetCompletion with remaining capital.
    SafetyOSHA violations and incident reports.
    ScheduleBonus for finishing before deadline.
    Anti-HackInvalid actions, timeouts, and budget failure.

    Evidence

    Baseline, trained policy surface, and solvable oracle

    The included artifact shows random actions versus the deterministic demo policy. Constrained-choice training artifacts can be dropped into the same folder and linked here.

    Training story

    • Free-form JSON actions exposed the core RL failure mode: malformed generations can collapse reward variance.
    • Construx-RL now supports a constrained-choice policy surface that maps model selections into valid environment actions.
    • The environment remains fully inspectable: every reward comes from visible project state, safety, budget, and schedule checks.
    • New training graphs can be dropped into demo_artifacts and surfaced here for the final demo.
